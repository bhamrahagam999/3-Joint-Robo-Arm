An Arduino-based control system programmed in C++ for a 3-DOF (degree of freedom) robotic arm.

### Key Features
* **Multi-Axis Servo Control:** Drives 3 independent servo motors representing the base, shoulder, and elbow joints.
* **Analog Potentiometer Mapping:** Reads continuous analog inputs from 3 potentiometers (0–1023) and maps them using C++ logic to precise servo angle positions.
* **Real-Time Positional Tracking:** Converts analog voltage variations into smooth, direct joint articulation.

### Tech Stack
* **Language:** C++ / Arduino Framework
* **Hardware Simulated:** Arduino Uno, 3 Servo Motors, 3 Potentiometers, External Power Rail, Push Button
* **Simulation Platform:** Tinkercad
